## 📝 Important Notes

### Veo 3 Ultra API Integration
The current implementation includes **PLACEHOLDER** code for Veo 3 Ultra API as the actual API endpoints are not yet publicly available. When the API becomes available, you need to update:

1. `VeoService._call_veo_api()` - Replace with real API endpoint
2. `VeoService.generate_video_scene()` - Update request format
3. `VeoService.poll_job_status()` - Update polling logic
4. `VeoService.generate_storyboard_frame()` - Real image generation
5. `VeoService.merge_scenes()` - Real video merging

### Required API Keys
Before running the application, you must configure:
- `GEMINI_API_KEY` - Google Gemini API key
- `VEO_API_KEY` - Veo 3 Ultra API key (when available)

### Environment Setup
1. Copy `backend/.env.example` to `backend/.env`
2. Copy `frontend/.env.example` to `frontend/.env.local`
3. Update API keys in `backend/.env`
4. Run `./setup.sh` or `docker-compose up`
